# BANK UNDER PRESSURE — משחק גיוס פיקוחי

פרויקט React/TypeScript/Vite מלא בעברית וב־RTL, שנועד להדגמה, לפיתוח המשך ב־Claude Code ולהפצה באתר ציבורי. התרחיש, הבנק והנתונים **בדיוניים**. אין שירות שרת, כניסה, איסוף מידע אישי, קריאות AI או מסד נתונים. ההתקדמות נשמרת מקומית בדפדפן בלבד.

## הפעלה

נדרש Node.js 20.19+ (מומלץ Node 22) ומנהל החבילות npm.

```bash
npm install
npm run dev
```

פתחו את הכתובת ש־Vite מציג (לרוב http://localhost:5173).

בדיקות לפני פרסום:

```bash
npm run check:data   # עקביות נתונים ואיזון מאזן
npm test             # בדיקות הסתעפויות, מסמכים, ניקוד ושמירת מצב
npm run build        # TypeScript + בניית קבצי פרסום
npm run preview      # תצוגת גרסת הייצור
```

> מצב הבדיקות העדכני, התיקונים שבוצעו והפריטים הפתוחים מתועדים ב־`docs/BUILD_STATUS.md` וב־`docs/RELEASE_CHECKLIST.md`.

## מה כבר בנוי?

- מסך פתיחה עם חוויית משחק מותאמת למסכים גדולים וקטנים.
- טבלת 21 מדדים לשלוש שנים, בחירה של 0–3 ללא הדגשת המסיחים.
- חקירת מסמך ראשון התלוי בבחירה; עד שתי ראיות לשמירה.
- מסלול מסיחים עם שאלת מנהל האגף שאינה עולה נקודות.
- מסמך שני ייעודי: ALCO, תוכנית אשראי, סקירת גזברות או מסמך מתקדם.
- המסמך המתקדם כולל **שני מסיחים**: איתנות מקורות המימון שעשויה לגרום לביטול הסיכון; ושחיקת רווחיות שעשויה להעביר את המוקד לסיכון עסקי. השחקן נדרש לשמור על הערכתו המקורית תוך שקלול הממתנים.
- שני רמזים אופציונליים, הפחתה של עד 10 נקודות מעצמאות בלבד.
- בחירה מרובה ללא הגבלה של גורמי שורש (בחירה גורפת מקבלת קנס), מבחן קשר סיבתי, אתגור CFO וסיכון משני.
- סיכום אחיד לכל המסלולים והכרעה פיקוחית אחת.
- ניקוד 100, פרופיל משוב והעתקה/שיתוף ללא חשיפת הפתרון בטקסט השיתוף.
- שמירת התקדמות מקומית, התחלה מחדש, בדיקות יחידה ראשוניות.

## שינוי תכנים

1. כל המספרים ההיסטוריים, מסמכי החקירה וראיות המסמכים נמצאים ב־`src/content/scenario.json`.
2. נוסחי שאלות, מסיחים ותשובות נמצאים בראש `src/App.tsx`, משקלי שורש וניקוד נמצאים ב־`src/game/engine.ts`.
3. אם משנים נתון כמותי, יש לעדכן את המסמכים, הראיות וסיכום העובדות האחיד באותו ערך. לאחר מכן להריץ `npm run check:data` ו־`npm test`.
4. כדי להציג קישור גיוס לציבור, יש להזין כתובת קיימת בלבד ב־`recruitmentUrl` בתוך `src/content/config.json`. שדה ריק מסתיר קישור.
5. לפני הפצה תחת זהות ארגונית רשמית יש לאשר ניסוחים, מיתוג, ואסמכתאות רגולטוריות בנפרד. אין להציג את הפרויקט כמוצר רשמי בלי אישור מתאים.

## פרסום

אפשר לפרסם את תיקיית `dist/` שנוצרת אחרי `npm run build` באחסון סטטי (Netlify, Vercel, GitHub Pages עם base מתאים). אין כתיבה לשרת ואין צורך במפתחות API.

## עקרונות שמירה על הוגנות

ההחלטה הסופית וסיכום העובדות **זהים בכל המסלולים**. בחירת מסיח לחקירה אינה מורידה נקודות. המסיח מפחית ניקוד רק כאשר השחקן מציג אותו כהסבר מרכזי לבעיית השורש, או בוחר הערכה שגויה בעקבותיו. רמזים מתומחרים מראש; המסמך השני אינו ״עזרה בתשלום״. ציון התוצאה הוא ציון משחקי שנועד למשוב בלבד, ולא ציון התאמה תעסוקתית.
