# מצב בדיקות — Claude Code, 21.10.2026

## הורצו בפועל

- `npm install` — הצליח. `npm audit` מדווח על 3 פגיעויות ב־`vitest`/`tinypool`/`@vitest/mocker` (כלי פיתוח בלבד, לא נכנסים ל־`dist`). תיקון מלא דורש `vitest@5` (שינוי שובר) ולא בוצע.
- `npm run check:data` — עבר: 21 מדדים, 11 מסמכים, 10 ראיות, מאזן מתאזן בכל שנה.
- `npm test` — עבר: 12 בדיקות (נוספו שתיים על `withSignals`).
- `npm run build` — עבר (`tsc --noEmit` + `vite build`, 282 kB JS / 15.7 kB CSS). הורץ על עותק של הפרויקט מחוץ ל־iCloud, ראו להלן.
- בדיקה ידנית בדפדפן (dev server): מתקדם, אשראי, מימון, ארבעה מסלולי מסיחים, "ללא חקירה נוספת", "ללא בחירה", ושדרוג למסמך המתקדם דרך ראיות. סיכום העובדות זהה בכל המסלולים.
- מסלול מתקדם: שני המסיחים מוצגים; בחירה ב'הרווחיות' לא חושפת משוב ומאפשרת תיקון; מעבר תקין להכרעה.
- רשת: אין בקשות לדומיינים חיצוניים; בחבילת `dist` אין `fetch`/מעקב.
- רוחבים 320/360/390/768/1440, כל שבעת השלבים, מסלול מתקדם ומסלול מסיחים: אין גלישה אופקית של העמוד ואין גלילה פנימית בטבלה (למעט חריגה של 2px ב־320).

## תיקונים שבוצעו

1. **ראיות ישנות בניקוד** — אחרי החלפת מדדי הפתיחה, ראיה ממסמך קודם נשארה בניקוד ובמונה ולא ניתן היה להסירה. נוספה `withSignals` ב־`engine.ts` (גוזמת ראיות ומאפסת את בחירת מנהל האגף כשהמסמך הראשון משתנה) + בדיקות.
2. **גלישת עמוד במובייל** — `.section-flow` הוא grid ופריטיו לא התכווצו מתחת לרוחב הטבלה. נוסף `grid-template-columns:minmax(0,1fr)`.
3. **טבלת המדדים במובייל** — המספרים ותיבות הסימון נדחקו מחוץ למסך. הוקטנו עמודות וריווחים; `min-width` של הטבלה ירד מ־660 ל־600.
4. **הטיית מיקום** — התשובה המועדפת הייתה ראשונה ב־3 מתוך 4 שאלות; פוזרה. לוגיקת הניקוד לא השתנתה.
5. **נגישות** — Escape סוגר מודל ומגירה, פוקוס ראשוני ב'ביטול' במודל האיפוס, גלילה מכבדת `prefers-reduced-motion`.

## ידוע ולא נפתר

- הגופן `Heebo` מוצהר ב־CSS אך אינו נטען (אין `@font-face`); בפועל Arial/גופן מערכת. טעינה מ־Google Fonts תהיה בקשה חיצונית, לכן לא נוספה. אפשר לארח מקומית ב־`public/`.
- לא נבדקה נגישות מקלדת מלאה לאורך כל השלבים, קורא מסך וניגודיות מדודה.
- לא נבדקו מכשירים פיזיים.

## הערת סביבה: תקיעות בגלל iCloud

הפרויקט נמצא תחת Desktop המסונכרן ל־iCloud; קבצי מקור ו־`node_modules` הופיעו כ־`compressed,dataless` וכל קריאה ממתינה להורדה, ולכן `tsc` ו־`vite build` נתקעו שוב ושוב (בנוסף לעומס מערכת). האימות הסופי (`check:data`, `npm test`, `npm run build`) הורץ על עותק זהה במקום מקומי, והכול עבר. מומלץ להעביר את הפרויקט מחוץ ל־Desktop. `package-lock.json` נוצר ב־`npm install` ואינו הופיע במקור.
